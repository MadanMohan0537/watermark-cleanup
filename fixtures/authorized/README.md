These files are authorized sample assets for tests and local demos. They were created for this repository. Do not upload other people's media.

- `sample.txt` and `sample.md` include a repeated overlay line on purpose.
- Image fixtures used by tests are generated in `tests/helpers/fixtures.ts`.
- Run `npm run generate:fixtures` to write PNG/PDF samples into this folder.
- Run `npm run generate:assets` to write the larger public demo image, Open Graph image, and `public/samples` copies.
